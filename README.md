# 💼 Job Box

**Job Box** is a modern, offline-first Flutter application that helps job seekers organize and track their job applications in one place. Keep track of applications, monitor hiring progress, save job descriptions, and never lose important details during your job search.

---

## ✨ Features

- 📋 Track unlimited job applications
- 📈 Visual hiring progress timeline
- 📝 Add notes for each application
- 🔗 Save job posting URLs
- 🖼️ Store Job Description (JD) screenshots
- 📅 Track application dates
- 📊 Application summary dashboard
- 🌙 Light & Dark mode support
- 📱 Clean Material 3 UI
- 🔒 Completely offline — no account required

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/job-box.git
```

### Navigate to the project

```bash
cd job_box
```

### Install dependencies

```bash

```

### Run the application

```bash
flutter run
```

## 🎯 Why Job Box?

Job hunting often involves applying through multiple platforms, keeping track of interview stages, and saving different job descriptions.

**Job Box** keeps everything organized in one place while ensuring your data stays completely on your device.

---

## 🔒 Privacy

Your data never leaves your device.

- No account
- No cloud sync
- No tracking
- No ads
- Fully offline
